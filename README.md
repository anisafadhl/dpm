PT Duta Parama Mandiri - Web Portofolio (Laravel 12 + Tailwind CSS v4)

Selamat datang di repository resmi website portofolio PT Duta Parama Mandiri! Website ini dirancang untuk menampilkan portofolio proyek arsitektur, desain interior, dan konstruksi perusahaan secara interaktif, modern, dan dinamis menggunakan framework Laravel 12 dan styling tercanggih Tailwind CSS v4 (Vite).

🚀 Fitur Utama
Desain Modern & Responsif: Berfungsi optimal di semua perangkat (HP, Tablet, Desktop) berkat Tailwind CSS v4.
Dukungan Dark Mode: Pengguna dapat dengan mudah beralih antara tema Terang (Light) dan Gelap (Dark).
Dashboard Admin Dinamis: Admin dapat melakukan login langsung dari Navbar untuk mengakses fitur manajemen portofolio (Tambah, Edit, Hapus Proyek).
Halaman Struktur Organisasi: Visualisasi bagan organogram tim profesional PT Duta Parama Mandiri secara interaktif.
Portofolio Terhubung Database: Data portofolio di-load secara dinamis dari database MySQL.

🛠️ Teknologi & Stack yang Digunakan
Framework: Laravel 12.x
Build Tool / Compiler: Vite 6.x
Styling: Tailwind CSS v4.0 (konfigurasi @theme modern)
Database: MySQL / MariaDB
Ikon: Font Awesome 6.4
